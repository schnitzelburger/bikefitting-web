# Bikefit Videoanalyse

Eine private Webanwendung zur Messung der Sitzposition auf dem Rennrad. Das Projekt nutzt ein lokales KI Modell, um Gelenkwinkel aus einem Video zu berechnen und Empfehlungen zur Sattelhöhe zu geben.

## Technologie

* Backend: FastAPI in Python
* Frontend: HTML und HTMX
* KI Modell: Ultralytics YOLO Pose
* Bereitstellung: Docker Compose

## Starten

Öffne das Terminal im Projektordner und starte den Container:

```bash
docker compose up
```
